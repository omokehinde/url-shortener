# URL Shortener Setup Guide

## Requirements
- Node.js v18+
- npm v9+

## Installation
1. Clone repository
2. Install dependencies:
```bash
cd backend && npm install # Backend 
cd ../frontend && npm install # Frontend
```
## Backend
### Run application
```bash
npm run dev # Run server in development 
npm start # Run in production
```

### Run tests
```bash
npm run test 
npm test -- --coverage # Test coverage report
npm run test:watch 
```

## Frontend
### Run application
```bash
npm start
